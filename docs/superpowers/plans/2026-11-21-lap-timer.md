# Lap Timer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A web page that uses a phone's rear camera above a track to count laps per RC car, identified by a coloured sticky note on the roof, with Practice and Race modes.

**Architecture:** Each video frame, a small rectangle of pixels around the finish line (the zone) is read and compared against the learned hue of each car. Pure modules do colour maths, calibration, detection, crossing logic and race rules; thin browser modules do camera, storage and DOM. `main.js` connects them.

**Tech Stack:** Plain HTML, CSS and JavaScript ES modules. No framework, no dependencies, no build step. Tests with Node's built-in runner (`node --test`, Node 24 is installed).

**Spec:** `docs/superpowers/specs/2026-11-21-lap-timer-design.md`

## Global Constraints

- No npm dependencies and no build step. The browser loads `src/*.js` directly as ES modules.
- `src/color.js`, `src/calibrate.js`, `src/detector.js`, `src/laps.js`, `src/race.js` must not touch `document`, `window`, `navigator` or `localStorage`. `src/ui.js` and `src/storage.js` must not touch them at import time (tests import them in Node).
- All times are in seconds. All hues are in degrees, 0–360. Pixel buffers are RGBA `Uint8ClampedArray`, 4 bytes per pixel.
- Fixed values from the spec: maximum 4 cars; saturation ≥ 0.35 and value ≥ 0.30; changed-pixel RGB distance > 40; note fraction ≥ 2 %; hue separation ≥ 30°; threshold = max(30 % of calibrated area, noise floor + 1 %); 3 absent frames to leave the zone; defaults: tolerance ±15°, minimum lap time 2 s, lap target 10; baseline averages 10 frames, a car averages 5 frames; zone image about 80 pixels on the long side.
- Prefix every shell command with `source ~/.bash_profile &&` (the user's machine needs it for the correct `git` and `node`).
- Work on branch `main`. Do not create branches. Do not push unless a step says so.

// Colours as the camera might see them. Hues: FLOOR 33°, PINK 329°,
// GREEN 135°, BLUE 221°, ORANGE 33°. GREY is not saturated.
export const FLOOR = [200, 160, 110];
export const PINK = [255, 60, 160];
export const GREEN = [40, 200, 80];
export const BLUE = [40, 100, 230];
export const ORANGE = [255, 140, 0];
export const GREY = [130, 130, 135];

// mix([[800, FLOOR], [200, PINK]]) → RGBA buffer of 1000 pixels.
export function mix(parts) {
  const total = parts.reduce((sum, [count]) => sum + count, 0);
  const data = new Uint8ClampedArray(total * 4);
  let i = 0;
  for (const [count, [r, g, b]] of parts) {
    for (let k = 0; k < count; k++) {
      data[i++] = r;
      data[i++] = g;
      data[i++] = b;
      data[i++] = 255;
    }
  }
  return data;
}

export function fill(count, rgb) {
  return mix([[count, rgb]]);
}

export function near(actual, expected, eps = 0.5) {
  assert.ok(
    Math.abs(actual - expected) <= eps,
    `expected ${actual} to be within ${eps} of ${expected}`,
  );
}

```js
export const MIN_SATURATION = 0.35;
export const MIN_VALUE = 0.3;

export function rgbToHsv(r, g, b) {
  const max = Math.max(r, g, b);
  const min = Math.min(r, g, b);
  const delta = max - min;
  let h = 0;
  if (delta > 0) {
    if (max === r) h = ((g - b) / delta) % 6;
    else if (max === g) h = (b - r) / delta + 2;
    else h = (r - g) / delta + 4;
    h *= 60;
    if (h < 0) h += 360;
  }
  return { h, s: max === 0 ? 0 : delta / max, v: max / 255 };
}

export function hueDistance(a, b) {
  const d = Math.abs(a - b) % 360;
  return d > 180 ? 360 - d : d;
}

export function circularMeanHue(hues) {
  let x = 0;
  let y = 0;
  for (const hue of hues) {
    const rad = (hue * Math.PI) / 180;
    x += Math.cos(rad);
    y += Math.sin(rad);
  }
  const mean = (Math.atan2(y, x) * 180) / Math.PI;
  return (mean + 360) % 360;
}

export function isSaturated(s, v) {
  return s >= MIN_SATURATION && v >= MIN_VALUE;
}

// Fraction of the pixels in an RGBA buffer that are saturated and whose hue
// is within `tolerance` degrees of `hue`.
export function matchFraction(data, hue, tolerance) {
  const pixels = data.length / 4;
  if (pixels === 0) return 0;
  let count = 0;
  for (let i = 0; i < data.length; i += 4) {
    const { h, s, v } = rgbToHsv(data[i], data[i + 1], data[i + 2]);
    if (isSaturated(s, v) && hueDistance(h, hue) <= tolerance) count++;
  }
  return count / pixels;
}
```

```js
import {
  rgbToHsv,
  hueDistance,
  circularMeanHue,
  isSaturated,
  matchFraction,
} from './color.js';

export const CHANGE_DISTANCE = 40;
export const MIN_NOTE_FRACTION = 0.02;
export const MIN_HUE_SEPARATION = 30;
export const AREA_FACTOR = 0.3;
export const NOISE_MARGIN = 0.01;

const HUE_BINS = 36;

// Average of several RGBA buffers of the same length.
export function averageFrames(frames) {
  const length = frames[0].length;
  const sum = new Float64Array(length);
  for (const frame of frames) {
    for (let i = 0; i < length; i++) sum[i] += frame[i];
  }
  const result = new Uint8ClampedArray(length);
  for (let i = 0; i < length; i++) result[i] = sum[i] / frames.length;
  return result;
}

// Finds the dominant hue of the saturated pixels that differ from the
// baseline. Returns null when there are none.
export function findNoteHue(baseline, frame) {
  const pixels = frame.length / 4;
  const hues = [];
  const bins = new Array(HUE_BINS).fill(0);
  for (let i = 0; i < frame.length; i += 4) {
    const dr = frame[i] - baseline[i];
    const dg = frame[i + 1] - baseline[i + 1];
    const db = frame[i + 2] - baseline[i + 2];
    if (Math.hypot(dr, dg, db) <= CHANGE_DISTANCE) continue;
    const { h, s, v } = rgbToHsv(frame[i], frame[i + 1], frame[i + 2]);
    if (!isSaturated(s, v)) continue;
    hues.push(h);
    bins[binOf(h)]++;
  }
  if (hues.length === 0) return null;
  const peak = bins.indexOf(Math.max(...bins));
  const selected = new Set([
    (peak + HUE_BINS - 1) % HUE_BINS,
    peak,
    (peak + 1) % HUE_BINS,
  ]);
  const hue = circularMeanHue(hues.filter((h) => selected.has(binOf(h))));
  return { hue, noteFraction: hues.length / pixels };
}

function binOf(hue) {
  return Math.floor(hue / (360 / HUE_BINS)) % HUE_BINS;
}

// Mean hue of the saturated pixels in a square around (x, y) of a
// width × height RGBA image. Returns null when none is saturated.
export function hueAround(frame, width, height, x, y, radius) {
  const hues = [];
  for (let py = y - radius; py <= y + radius; py++) {
    for (let px = x - radius; px <= x + radius; px++) {
      if (px < 0 || py < 0 || px >= width || py >= height) continue;
      const i = (py * width + px) * 4;
      const { h, s, v } = rgbToHsv(frame[i], frame[i + 1], frame[i + 2]);
      if (isSaturated(s, v)) hues.push(h);
    }
  }
  return hues.length === 0 ? null : circularMeanHue(hues);
}

// Learns a car from a frame with the car on the finish line. When `hue` is
// given (the user tapped the note), the automatic hue detection is skipped.
export function calibrateCar({
  baseline,
  frame,
  tolerance,
  existingCars,
  hue = null,
}) {
  let carHue = hue;
  if (carHue === null) {
    const note = findNoteHue(baseline, frame);
    if (note === null || note.noteFraction < MIN_NOTE_FRACTION) {
      return { ok: false, reason: 'no-note' };
    }
    carHue = note.hue;
  }
  const area = matchFraction(frame, carHue, tolerance);
  if (area < MIN_NOTE_FRACTION) return { ok: false, reason: 'no-note' };

  const carIndex = existingCars.findIndex(
    (car) => hueDistance(car.hue, carHue) < MIN_HUE_SEPARATION,
  );
  if (carIndex !== -1) {
    return { ok: false, reason: 'too-close-to-car', carIndex };
  }

  const noiseFloor = matchFraction(baseline, carHue, tolerance);
  if (noiseFloor > area / 2) {
    return { ok: false, reason: 'too-close-to-floor' };
  }

  const threshold = Math.max(AREA_FACTOR * area, noiseFloor + NOISE_MARGIN);
  return { ok: true, car: { hue: carHue, threshold, noiseFloor } };
}

import { matchFraction } from './color.js';

// Fraction of zone pixels that match each car's hue.
export function matchLevels(data, cars, tolerance) {
  return cars.map((car) => matchFraction(data, car.hue, tolerance));
}

// A car is present when its level is above its own threshold.
export function presence(levels, cars) {
  return levels.map((level, index) => level > cars[index].threshold);
}

export const ABSENT_FRAMES = 3;

export function createTracker() {
  return { present: false, misses: 0, lastCrossing: null };
}

// Feeds one frame into the tracker. Returns true when this frame is a
// counted crossing: the car entered the zone, and the minimum lap time has
// passed since the last counted crossing.
export function updateTracker(tracker, isPresent, time, minLapTime) {
  if (!isPresent) {
    if (tracker.present) {
      tracker.misses++;
      if (tracker.misses >= ABSENT_FRAMES) {
        tracker.present = false;
        tracker.misses = 0;
      }
    }
    return false;
  }
  tracker.misses = 0;
  if (tracker.present) return false;
  tracker.present = true;
  if (
    tracker.lastCrossing !== null &&
    time - tracker.lastCrossing < minLapTime
  ) {
    return false;
  }
  tracker.lastCrossing = time;
  return true;
}

import { createTracker, updateTracker } from './laps.js';

export function createSession({
  mode,
  carCount,
  lapTarget = 10,
  minLapTime = 2,
}) {
  return {
    mode,
    lapTarget,
    minLapTime,
    goTime: null,
    cars: Array.from({ length: carCount }, () => ({
      tracker: createTracker(),
      startTime: null,
      lastCrossing: null,
      laps: [],
      finishTime: null,
    })),
  };
}

// Race mode: sets the time of "Go". Crossings before it are ignored.
export function startRace(session, goTime) {
  session.goTime = goTime;
}

// Feeds one frame into the session. `presence[i]` says if car i is in the
// zone. Returns the events of this frame.
export function onFrame(session, presence, time) {
  const events = [];
  const racing = session.mode === 'race';
  const beforeGo =
    racing && (session.goTime === null || time < session.goTime);

  session.cars.forEach((car, index) => {
    const crossed = updateTracker(
      car.tracker,
      presence[index],
      time,
      session.minLapTime,
    );
    if (beforeGo) {
      // A crossing before "Go" must not block the first lap.
      car.tracker.lastCrossing = null;
      return;
    }
    if (!crossed || car.finishTime !== null) return;

    if (racing) {
      car.laps.push(time - (car.lastCrossing ?? session.goTime));
      car.lastCrossing = time;
      if (car.laps.length >= session.lapTarget) {
        car.finishTime = time;
        events.push({ car: index, type: 'finish' });
      } else {
        events.push({ car: index, type: 'lap' });
      }
    } else if (car.startTime === null) {
      car.startTime = time;
      car.lastCrossing = time;
      events.push({ car: index, type: 'start' });
    } else {
      car.laps.push(time - car.lastCrossing);
      car.lastCrossing = time;
      events.push({ car: index, type: 'lap' });
    }
  });
  return events;
}

export function carStats(session, index, now) {
  const car = session.cars[index];
  const start = session.mode === 'race' ? session.goTime : car.startTime;
  let total = null;
  if (start !== null && now >= start) {
    total = (car.finishTime ?? now) - start;
  }
  return {
    laps: car.laps.length,
    lastLap: car.laps.length > 0 ? car.laps[car.laps.length - 1] : null,
    bestLap: car.laps.length > 0 ? Math.min(...car.laps) : null,
    total,
    finished: car.finishTime !== null,
  };
}

// Car indices, best position first. Practice keeps the car order.
export function standings(session) {
  const order = session.cars.map((_, index) => index);
  if (session.mode !== 'race') return order;
  return order.sort((a, b) => {
    const carA = session.cars[a];
    const carB = session.cars[b];
    if (carA.finishTime !== null || carB.finishTime !== null) {
      if (carA.finishTime === null) return 1;
      if (carB.finishTime === null) return -1;
      return carA.finishTime - carB.finishTime;
    }
    if (carA.laps.length !== carB.laps.length) {
      return carB.laps.length - carA.laps.length;
    }
    const lastA = carA.lastCrossing ?? Infinity;
    const lastB = carB.lastCrossing ?? Infinity;
    if (lastA !== lastB) return lastA < lastB ? -1 : 1;
    return a - b;
  });
}

export function isRaceOver(session) {
  return (
    session.mode === 'race' &&
    session.cars.every((car) => car.finishTime !== null)
  );
}

const KEY = 'race-car-timer-setup';

export function serializeSetup(setup) {
  const { baseline } = setup;
  return JSON.stringify({
    ...setup,
    baseline: baseline
      ? { ...baseline, data: Array.from(baseline.data) }
      : null,
  });
}

export function deserializeSetup(text) {
  try {
    const raw = JSON.parse(text);
    if (
      raw === null ||
      typeof raw !== 'object' ||
      !Array.isArray(raw.cars) ||
      typeof raw.settings !== 'object' ||
      raw.settings === null
    ) {
      return null;
    }
    return {
      zone: raw.zone ?? null,
      baseline: raw.baseline
        ? { ...raw.baseline, data: Uint8ClampedArray.from(raw.baseline.data) }
        : null,
      cars: raw.cars,
      settings: raw.settings,
    };
  } catch {
    return null;
  }
}

export function saveSetup(setup) {
  try {
    localStorage.setItem(KEY, serializeSetup(setup));
  } catch {
    // Storage is not available (private mode, quota). The app works without.
  }
}

export function loadSetup() {
  try {
    const text = localStorage.getItem(KEY);
    return text === null ? null : deserializeSetup(text);
  } catch {
    return null;
  }
}

export function clearSetup() {
  try {
    localStorage.removeItem(KEY);
  } catch {
    // Nothing to clear.
  }
}

export function formatTime(seconds) {
  if (seconds === null) return '–';
  const hundredths = Math.round(seconds * 100);
  const minutes = Math.floor(hundredths / 6000);
  const rest = hundredths - minutes * 6000;
  const whole = String(Math.floor(rest / 100)).padStart(2, '0');
  const fraction = String(rest % 100).padStart(2, '0');
  return `${minutes}:${whole}.${fraction}`;
}

export function hueToCss(hue) {
  return `hsl(${Math.round(hue)} 90% 55%)`;
}

// Pointer position as fractions (0–1) of the element's box.
export function normalizedPoint(event, element) {
  const rect = element.getBoundingClientRect();
  const clamp = (value) => Math.min(1, Math.max(0, value));
  return {
    x: clamp((event.clientX - rect.left) / rect.width),
    y: clamp((event.clientY - rect.top) / rect.height),
  };
}

// Browsers allow sound only after a user gesture: call unlock() from a
// click handler before the first beep().
export function createBeeper() {
  let context = null;
  return {
    unlock() {
      if (context === null) context = new AudioContext();
      if (context.state === 'suspended') context.resume();
    },
    beep(frequency = 880, duration = 0.12) {
      if (context === null) return;
      const oscillator = context.createOscillator();
      const gain = context.createGain();
      oscillator.frequency.value = frequency;
      gain.gain.value = 0.3;
      oscillator.connect(gain).connect(context.destination);
      oscillator.start();
      oscillator.stop(context.currentTime + duration);
    },
  };
}

export const ZONE_LONG_SIDE = 80;

// False when the page is not served over HTTPS (or localhost), or the
// browser has no camera API.
export function cameraSupported() {
  return Boolean(navigator.mediaDevices && navigator.mediaDevices.getUserMedia);
}

export async function openCamera(video) {
  const stream = await navigator.mediaDevices.getUserMedia({
    audio: false,
    video: {
      facingMode: { ideal: 'environment' },
      width: { ideal: 1280 },
      height: { ideal: 720 },
      frameRate: { ideal: 60 },
    },
  });
  video.srcObject = stream;
  await video.play();
  return stream;
}

// Calls callback(time) once per video frame, time in seconds. Uses the
// frame's media time when the browser gives it. Returns a stop function.
export function onFrames(video, callback) {
  let stopped = false;
  if ('requestVideoFrameCallback' in HTMLVideoElement.prototype) {
    const step = (now, metadata) => {
      if (stopped) return;
      callback(metadata.mediaTime);
      video.requestVideoFrameCallback(step);
    };
    video.requestVideoFrameCallback(step);
  } else {
    const step = () => {
      if (stopped) return;
      callback(performance.now() / 1000);
      requestAnimationFrame(step);
    };
    requestAnimationFrame(step);
  }
  return () => {
    stopped = true;
  };
}

// Returns readZone(zone): the pixels of the zone, downscaled so that the
// long side is ZONE_LONG_SIDE pixels. `zone` is in fractions of the video.
export function createZoneReader(video) {
  const canvas = document.createElement('canvas');
  const context = canvas.getContext('2d', { willReadFrequently: true });
  return function readZone(zone) {
    const sx = zone.x * video.videoWidth;
    const sy = zone.y * video.videoHeight;
    const sw = Math.max(1, zone.w * video.videoWidth);
    const sh = Math.max(1, zone.h * video.videoHeight);
    const scale = ZONE_LONG_SIDE / Math.max(sw, sh);
    const width = Math.max(1, Math.round(sw * scale));
    const height = Math.max(1, Math.round(sh * scale));
    if (canvas.width !== width) canvas.width = width;
    if (canvas.height !== height) canvas.height = height;
    context.drawImage(video, sx, sy, sw, sh, 0, 0, width, height);
    return {
      data: context.getImageData(0, 0, width, height).data,
      width,
      height,
    };
  };
}

function showMessage(text) {
  $('message-text').textContent = text;

async function startCamera() {
  $('message').hidden = true;
  if (!cameraSupported()) {
    showMessage(
      'Camera access is not available. Open this page over HTTPS in Chrome.',
    );
    return;
  }
  try {
    await openCamera(video);
  } catch (error) {
    showMessage(`Could not open the camera: ${error.message}`);
    return;
  }
  const ratio = video.videoWidth / video.videoHeight;
  stage.style.aspectRatio = `${video.videoWidth} / ${video.videoHeight}`;
  stage.style.width = `min(100vw, calc(100dvh * ${ratio}))`;
  overlay.width = video.videoWidth;
  overlay.height = video.videoHeight;
  readZone = createZoneReader(video);
  if (stopFrames) stopFrames();
  stopFrames = onFrames(video, handleFrame);
}

// ---- Frame loop -----------------------------------------------------------

function handleFrame(time) {
  lastTime = time;
  drawOverlay();
  if (!setup.zone) return;

  const image = readZone(setup.zone);

  // A stored baseline from another camera resolution cannot be used.
  if (
    setup.baseline &&
    (setup.baseline.width !== image.width ||
      setup.baseline.height !== image.height)
  ) {
    setup.baseline = null;
    setup.cars = [];
    save();
    renderSetup();
  }

  if (collector) {
    collector.frames.push(image);
    if (collector.frames.length >= collector.count) {
      const done = collector;
      collector = null;
      done.resolve({
        data: averageFrames(done.frames.map((frame) => frame.data)),
        width: image.width,
        height: image.height,
      });
    }
  }

  levels = matchLevels(image.data, setup.cars, setup.settings.tolerance);

  if (session === null) {
    updateMeters();
    return;
  }
  updateCountdown(time);
  if (frozenTime === null) {
    const events = onFrame(session, presence(levels, setup.cars), time);
    for (const event of events) {
      if (event.type === 'finish') beeper.beep(1320, 0.5);
      else beeper.beep(880, 0.12);
    }
    if (isRaceOver(session)) endRace(time);
  }
  renderRun(frozenTime ?? time);
}

// Resolves with the average of the next `count` zone images.
function collect(count) {
  return new Promise((resolve) => {
    collector = { frames: [], count, resolve };
  });
}

function drawOverlay() {
  const context = overlay.getContext('2d');
  context.clearRect(0, 0, overlay.width, overlay.height);
  const zone = draftZone ?? setup.zone;
  if (!zone) return;
  context.lineWidth = Math.max(3, overlay.width / 200);
  context.strokeStyle = draftZone ? '#ffd60a' : '#35c759';
  context.strokeRect(
    zone.x * overlay.width,
    zone.y * overlay.height,
    zone.w * overlay.width,
    zone.h * overlay.height,
  );
}

function setHint(text) {
  $('hint').textContent = text;

function nextHint() {
  if (!setup.zone) {
    return 'Press "Set zone" and drag a box over the finish strip.';
  }
  if (!setup.baseline) {
    return 'Take all cars out of the zone, then press "Capture empty track".';
  }
  if (setup.cars.length === 0) {
    return 'Put one car on the finish line and press "Add car".';
  }
  if (setup.cars.length < MAX_CARS) {
    return 'Add the next car, or press Start.';
  }
  return 'Press Start.';
}

function renderSetup() {
  const { zone, baseline, cars, settings } = setup;
  const canAdd = baseline !== null && cars.length < MAX_CARS;
  $('capture-baseline').disabled = zone === null;
  $('add-car').disabled = !canAdd;
  $('tap-note').disabled = !canAdd;
  $('start').disabled = zone === null || baseline === null || cars.length === 0;

  document.querySelector(
    `input[name="mode"][value="${settings.mode}"]`,
  ).checked = true;
  $('lap-target').value = settings.lapTarget;
  $('lap-target').disabled = settings.mode !== 'race';
  $('tolerance').value = settings.tolerance;
  $('tolerance-value').textContent = `±${settings.tolerance}°`;
  $('min-lap').value = settings.minLapTime;
  $('min-lap-value').textContent = `${settings.minLapTime} s`;

  $('cars').replaceChildren(...cars.map(carItem));
  setHint(nextHint());
}

function carItem(car, index) {
  const item = document.createElement('li');

  const swatch = document.createElement('span');
  swatch.className = 'swatch';
  swatch.style.background = hueToCss(car.hue);

  const name = document.createElement('input');
  name.type = 'text';
  name.maxLength = 12;
  name.value = car.name;
  name.addEventListener('change', () => {
    car.name = name.value.trim() || `Car ${index + 1}`;
    name.value = car.name;
    save();
  });

  const bar = document.createElement('div');
  bar.className = 'bar';
  const fill = document.createElement('div');
  fill.className = 'fill';
  bar.append(fill);

  const remove = document.createElement('button');
  remove.className = 'quiet';
  remove.textContent = 'Remove';
  remove.addEventListener('click', () => {
    setup.cars.splice(index, 1);
    save();
    renderSetup();
  });

  item.append(swatch, name, bar, remove);
  return item;
}

// The white mark in the middle of a bar is the car's threshold.
function updateMeters() {
  document.querySelectorAll('#cars .fill').forEach((fill, index) => {
    const car = setup.cars[index];
    if (!car) return;
    const level = levels[index] ?? 0;
    fill.style.width = `${Math.min(100, (level / car.threshold) * 50)}%`;
    fill.classList.toggle('on', level > car.threshold);
  });
}

function calibrationMessage(result) {
  if (result.reason === 'no-note') {
    return 'No coloured note found. Put the car on the finish line.';
  }
  if (result.reason === 'too-close-to-car') {
    const other = setup.cars[result.carIndex].name;
    return `Too close to ${other}. Use a different colour.`;
  }
  return 'This colour is too close to the floor or the strip. Use a different colour.';
}

function applyCalibration(result) {
  if (!result.ok) {
    setHint(calibrationMessage(result));
    return;
  }
  setup.cars.push({ name: `Car ${setup.cars.length + 1}`, ...result.car });
  save();
  renderSetup();
}

async function handleTap(point) {
  const { zone } = setup;
  const zx = (point.x - zone.x) / zone.w;
  const zy = (point.y - zone.y) / zone.h;
  if (zx < 0 || zx >= 1 || zy < 0 || zy >= 1) {
    setHint('Tap the note while the car is on the finish line, inside the box.');
    return;
  }
  const image = await collect(CAR_FRAMES);
  const hue = hueAround(
    image.data,
    image.width,
    image.height,
    Math.floor(zx * image.width),
    Math.floor(zy * image.height),
    TAP_RADIUS,
  );
  if (hue === null) {
    setHint('No colour found at that point. Tap the middle of the note.');
    return;
  }
  applyCalibration(
    calibrateCar({
      baseline: setup.baseline.data,
      frame: image.data,
      tolerance: setup.settings.tolerance,
      existingCars: setup.cars,
      hue,
    }),
  );
}

overlay.addEventListener('pointerdown', (event) => {
  if (session !== null) return;
  const point = normalizedPoint(event, overlay);
  if (pointerMode === 'tap') {
    pointerMode = 'none';
    handleTap(point);
  } else if (pointerMode === 'zone') {
    overlay.setPointerCapture(event.pointerId);
    dragStart = point;
  }
});

overlay.addEventListener('pointermove', (event) => {
  if (dragStart === null) return;
  const point = normalizedPoint(event, overlay);
  draftZone = {
    x: Math.min(dragStart.x, point.x),
    y: Math.min(dragStart.y, point.y),
    w: Math.abs(point.x - dragStart.x),
    h: Math.abs(point.y - dragStart.y),
  };
});

function finishDrag() {
  if (dragStart === null) return;
  const zone = draftZone;
  dragStart = null;
  draftZone = null;
  pointerMode = 'none';
  if (zone === null || zone.w < MIN_ZONE_SIZE || zone.h < MIN_ZONE_SIZE) {
    setHint('The box is too small. Press "Set zone" and try again.');
    return;
  }
  // The baseline and the cars were measured in the old zone.
  setup.zone = zone;
  setup.baseline = null;
  setup.cars = [];
  save();
  renderSetup();
}

// Shows 3, 2, 1 before "Go" and "Go" for one second after it.
function updateCountdown(time) {
  if (session.mode !== 'race' || session.goTime === null) return;
  if (frozenTime !== null) return;
  const element = $('countdown');
  const remaining = session.goTime - time;
  if (remaining > 0) {
    const number = Math.ceil(remaining);
    if (countdownShown !== number) {
      countdownShown = number;
      element.textContent = String(number);
      element.hidden = false;
      beeper.beep(440, 0.15);
    }
  } else if (remaining > -1) {
    if (countdownShown !== 'go') {
      countdownShown = 'go';
      element.textContent = 'Go';
      element.hidden = false;
      beeper.beep(880, 0.5);
    }
  } else {
    element.hidden = true;
  }
}

function cell(text) {
  const element = document.createElement('td');
  element.textContent = text;
  return element;
}

function renderRun(now) {
  const race = session.mode === 'race';
  const rows = standings(session).map((carIndex, position) => {
    const car = setup.cars[carIndex];
    const stats = carStats(session, carIndex, now);
    const row = document.createElement('tr');

    const name = document.createElement('td');
    const swatch = document.createElement('span');
    swatch.className = 'swatch';
    swatch.style.background = hueToCss(car.hue);
    name.append(swatch, ` ${car.name}`);

    row.append(
      cell(String(position + 1)),
      name,
      cell(race ? `${stats.laps}/${session.lapTarget}` : String(stats.laps)),
      cell(formatTime(stats.lastLap)),
      cell(formatTime(stats.bestLap)),
      cell(formatTime(stats.total)),
    );
    return row;
  });
  $('standings').replaceChildren(...rows);
}

# race-car-timer

A lap timer for small remote-controlled cars. A phone above the track watches
the finish line through its camera and counts the laps of each car.

Open on the phone (Chrome, Android): https://upeter.github.io/race-car-timer/

## What you need

- A phone fixed above the track, camera pointing straight down at the finish
  line.
- A coloured sticky note on the roof of each car (maximum 4 cars). Use colours
  that differ clearly from each other and from the floor. On a wood floor use
  pink, green and blue, not orange or yellow.
- Good, even light.

## Setup

1. **Set zone**: drag a box over the finish line, about one car length wide.
2. **Capture empty track**: with no car in the box.
3. **Add car**: put one car on the finish line and press the button. Repeat
   for each car. The bar next to a car shows how well the camera sees its
   note; the white mark is the level at which a crossing counts.
4. Select **Practice** or **Race** (with a number of laps) and press **Start**.

If a pass is not counted, add light, use a larger note, or increase the colour
tolerance in Settings.

## Modes

- **Practice**: a car's clock starts on its first crossing. Each later
  crossing is a lap.
- **Race**: cars start behind the line. After the countdown, each crossing is
  a lap. A car finishes at the lap target.

No build step and no dependencies.

npm test                    # unit tests (Node 20 or later)
python3 -m http.server 8000 # then open http://localhost:8000/
```

The design is in `docs/superpowers/specs/2026-11-21-lap-timer-design.md`.
